**Owner** Agent A · **Estimate** 6 h · **Day** Wed 21 · **Priority** P0 · **Depends on** none

**Spec.** Per-rule partial credit s_k in [0,1] with a normalized violation magnitude v_k and a tolerance τ_k (budget 0.25, servings 0.30, guest range 0.20); binary rules stay {0,1}. 3. All existing verifier/pentest/property tests unchanged (677 passed)
4. tests/test_ttl_engine.py: with equal pass status the orchestrator returns the candidate with the higher (hard_macro, hard_micro)

**QA.** Run the 130-profile coherence gate: first-try pass rate and chosen-plan cost within noise of the previous build · Read 10 graded reports by hand: the numbers match the violation messages · No rule gives credit for overshoot beyond τ_k

**Definition of done.** Merged behind the gate · Graded fields visible in the API response and documented in docs/LIVING_PASS.md verifier section · Decision logged: reward formula and weights

#### A0-03 · DPP pick of three (planning/select.py)

**Owner** Agent A · **Estimate** 5 h · **Day** Fri 23 · **Priority** P0 · **Depends on** A0-04

**Spec.** Fast greedy MAP inference for a DPP (Chen, Zhang & Zhou 2018): kernel L = diag(q) S diag(q) with q = exp(α·R) (α = θ/(2(1−θ)), θ = 0.6) and S = cosine Gram over normalized descriptor blocks + δI; greedy with incremental Cholesky; deterministic. compose_candidates() and the Claude path deliver a verified pool (≤ 12); select_three(pool) returns the chosen ids and the determinant; the mock backend and POST /plan return `alternatives` (3) when `variants=3` is requested.

**Acceptance tests.**
1. tests/test_select.py: 1,000 synthetic pools (M=12): det(L_greedy) ≥ det(random triple) in ≥ 95%; ≥ 0.9 × brute-force max over all triples in ≥ 90%
2. Duplicates in the pool are never both chosen; a pool of < 3 returns what exists
3. On the 130 profiles the three chosen differ in ≥ 2 descriptor dimensions in ≥ 90% of cases
4. Determinism: same pool → same selection

**QA.** Eyeball 10 profiles: the three read as different parties, not the same party with different cake · θ sweep (0.4/0.6/0.8) recorded in the decision log with judge-free proxy: descriptor distance vs mean R

**Definition of done.** Merged behind the gate · API field `alternatives` documented in README · Determinant logged per request (B0-01)

**Research.** Chen, Zhang & Zhou, Fast Greedy MAP Inference for DPP (NeurIPS 2018) — arXiv 1709.05135 · Wilhelm et al., Practical Diversified Recommendations on YouTube with DPPs (CIKM 2018): keep the kernel PSD

**Telemetry.** candidate log: shown ids, determinant, θ

## Research digest

### Engine and data (digest, checked 21 Oct 2026)

- **Graded reward.** Planner-R1's dense shaped reward (λ all 1, schema-gated) made an 8B model beat GPT-5 on TravelPlanner; sparse pass/fail collapsed it. Adopt partial credit per rule with tolerances, safety weight 1.0, budget/servings 0.7, completeness 0.3; add TourPlanner's sigmoid gate (τ 0.75, k 28) for soft rewards in S1. (https://arxiv.org/abs/2509.25779)
- **Candidate log.** TRL 1.16.0 (15 Oct 2026) GRPO wants prompt-only rows, SFT wants prompt-completion; log one row per candidate with catalog_sha256, verifier_version, model_id, usage; the Claude API has no seed, so replay only the verifier. (https://huggingface.co/docs/trl/main/en/dataset_formats)
- **DPP pick of three.** Chen, Zhang & Zhou's fast greedy MAP (NeurIPS 2018): L = diag(q)·S·diag(q), q = exp(α·R), cosine S over normalized descriptor blocks; YouTube kept the kernel PSD after a 'catastrophic cliff'. θ = 0.6 to start. (https://arxiv.org/abs/1709.05135)
- **CP-SAT spike.** OR-Tools 9.15 (Jan 2026): Booleans per slot candidate, AddExactlyOne, integer cents, hints from the composer, assumptions + SufficientAssumptionsForInfeasibility for explanations; ~600 Booleans solve in tens of milliseconds. (https://developers.google.com/optimization/reference/python/sat/python/cp_model)
- **Verbalized Sampling.** Five responses with verbalized probabilities, tails below 0.10; 1.6–2.1× diversity, no accuracy loss; probabilities are a tail filter, not weights. Wrap PlanDraft in {candidates:[{probability, plan}]}. (https://arxiv.org/abs/2510.01171)
- **Backprompting.** Send every violation at once as a structured list from the sound verifier (4.6× lift in the LLM-Modulo travel study); self-critique collapses; cap at 3 rounds and keep the best-R draft. (https://arxiv.org/abs/2405.20625)
- **Prompt caching and tiers.** Haiku 5.5 $0.10/$0.50 per MTok with 0.05× cache reads; 512-token minimum cacheable prefix on 5.5 models (4,096 on Haiku 4.5); 20k calls ≈ $9. Sonnet 5.5 $2/$10 for hard briefs only. (https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- **Judge rubric.** G-Eval form-filling with rationale before verdict; swap order for pairwise; 10 self-contained items weighted 1.0/0.7/0.3; calibrate on 150–200 human labels (Spearman ≥ 0.5 with CI lower bound > 0.3). (https://arxiv.org/abs/2303.16634)
- **Benchmark statistics.** Mirror TravelPlanner's delivery, micro/macro and final pass; Miller's paired and clustered SEs; ~315–785 paired cases to detect a 5-point gap — a 50-case bench only sees 15–20-point gaps. (https://arxiv.org/abs/2411.00640)
- **Playwright + axe.** Playwright 1.62, axe-core 4.13; block on serious/critical; radiogroup keyboard pattern for the picker; assert the concept_picked payload. (https://playwright.dev/docs/accessibility-testing)
- **GRPO feasibility.** Qwen3-8B LoRA, G=8, vLLM colocate on one H100 ≈ 1 min/step; RunPod community H100 ≈ $2.69/h; $150 ≈ 5–10 pilot runs. (https://www.runpod.io/pricing)

## The planning protocol (S1–S8)

- **Research brief.** For every card in the coming sprint, one paragraph of best-known method, exact parameters, pitfalls and 1–3 confirmed references, produced by a research agent with dates and URLs checked. No card enters Ready without it.
- **Card = spec + tests + QA + DoD.** The spec names modules and settings; acceptance tests are written before the implementation; QA lists what a reviewer verifies beyond the tests; definition of done includes docs, telemetry and a decision-log entry.
- **Gate, not opinion.** A card moves to In review only when its tests are merged and the gate is green; to Done only after QA. WIP limit: five cards in progress across all agent lanes.
- **One decision a day.** Every design choice an agent cannot make alone is logged with the options and the reason; the log is the input to the next research brief.
- **Friday demo + exit checklist.** The sprint closes on the QA gate checklist, a two-minute recording, and the numbers from the nightly report; what failed becomes the first research question of the next sprint.
- **Next-sprint brief seeded now.** S1's brief is drafted on Sunday from this sprint's decision log: CP-SAT core rows and objective; judge calibration set design; intake schema; vendor calls.
